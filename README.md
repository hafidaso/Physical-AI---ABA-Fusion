# 🤖 Physical AI - ABA Fusion Program

Welcome to the repository for the **Physical AI** training program in collaboration with **ABA Fusion**.
This training program spans **two months** and focuses on integrating Artificial Intelligence and software engineering with physical systems (Hardware, IoT, Robotics, and Digital Twins).

## 🎯 Program Objectives
- **Embedded Systems Mastery:** Programming hardware using ESP32, C/C++, and FreeRTOS.
- **Internet of Things (IoT) & Connectivity:** Implementing real-time communication protocols like MQTT and WiFi.
- **Digital Twins & SCADA Interfaces:** Creating Python-based digital representations of physical hardware.
- **Physical AI Integration:** Bringing intelligent logic into sensor-actuator environments.

## 🗂️ Repository Structure

The curriculum is organized by days/workshops (`Jours`). Each folder contains the specific code, documentation, and assignments for that session. Please refer to the specific `README.md` files inside each directory for detailed project descriptions.

- **[Jour 1](./Jour%201/):** Smart Robot Digital Twin (SCADA) via MQTT and FreeRTOS.
- **[Jour 2](./Jour%202/):** ESP32 Hardware Basics and Wokwi Simulation using PlatformIO.
- **[Jour 3](./Jour%203/):** Multi-Sensor Acquisition with FreeRTOS & Wokwi Simulation (ESP32, BME280, Potentiometer, IR Sensor).
- **[Jour 4](./Jour%204/):** Contrôle d'Actionneurs et Interfaces Utilisateurs Physiques (Arduino Uno).
  - **[Ex1 - Jour 4](./Jour%204/Ex1%20-%20Jour%204/):** Contrôle interactif d'un afficheur 7 segments avec bouton poussoir (offset), potentiomètre, et LEDs de parité.
  - **[Motor Jour 4](./Jour%204/Motor%20Jour%204/):** Régulation de vitesse d'un moteur CC (L298N) par potentiomètre, acquisition DHT11 et affichage sur LCD I2C.
